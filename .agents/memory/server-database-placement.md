---
name: Размещение базы на сервере проекта
description: Уточнение пользователя для требований к серверу и дальнейшего переноса.
---

При подготовке требований к серверу учитывать, что база данных будет перенесена на тот же сервер, который обслуживает проект.

**Why:** Пользователь уточнил: «с учетом того что база данных будет перенесена на него».

**How to apply:** Рассчитывать ресурсы одновременно для приложения и PostgreSQL, включая рост данных, журналы и резервное копирование. Это уточнение не является разрешением выполнять перенос.
